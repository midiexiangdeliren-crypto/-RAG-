# text_sora_2_1_1

空，休息一下吧，你已经连续跑了好几个地方。

这件衣服不需要你做到这一步。

如果只是一件普通的剧院礼服，我也不会这么在意啦。

但是德克萨斯，我们已经知道了总监是贝洛内家的家主。你肯定比我更清楚，我的身份就不再是一个普普通通的演员。

平日的相处里他是一位和善的伯伯，但我……我心底里并不是彻底相信他不会借着我牵制你。

我需要他在我的身上挑不出错处，不论是基于一个演员的身份，还是什么其他的——

我会和你一起去的，空。

我知道啦，你肯定不会想让事情到那一步的。

但我也需要提前做好我的准备。

毕竟我从龙门跑来这里，就是为了能找到你这个我们都在乎的朋友。

而不是让大家因此陷入危险。
